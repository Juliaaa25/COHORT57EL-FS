GET :что бы получить данные
Safe: да
Идемпотентность: да, повтор дает один и тот же результат
Кэшируемость: да
Не использовать: для создания или изменения данных


POST: что бы что-то создать, например создать новый ресурс
Тело запроса: JSON
Safe: нет
Идемпотентность: нет, повтор запроса создаст дубликат
Кэшируемость: нет
Не использовать: получить данные

PUT: для полной замены ресурса
Тело запроса: JSON
Safe: нет
Идемпотентность: да
Кэшируемость: нет
Не использовать: если меняется только часть полей или нет возможностей отправить обьект целиком


PATCH: для частичного обновления
Тело запроса: JSON
Safe: нет
Идемпотентность: да
Кэшируемость: нет
Не использовать:

DELETE: для удаления ресурса
Тело запроса: нет
Safe: нет
Идемпотентность: да
Кэшируемость: нет
Не использовать: если запрещено физическое удаление данных

HTTP-статусы:
200 ok, когда произошло успешное чтение или обновление ресурса
201 OK, Created успешное создание ресурса (POST)
204 No Content успешное обновление без тела
400 Bad Request невалидные данные (валидация DTO)
404 Not Found ресурс не найден
409 Conflict конфликт состояний
500 Internal Server Error - неожиданная ошибка
